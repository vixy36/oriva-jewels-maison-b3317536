# Oriva Brilliance

Create a world-class luxury jewellery website for ORIVA JEWELS, a Hong Kong-based premium fine jewellery brand specializing in Natural and Lab Grown Diamond jewellery. The website should feel like an international luxury brand, not a local jewellery store or wholesale manufacturer. The visual identity must be inspired by high-end brands such as Graff, Tiffany & Co., Cartier, VRAI, Ring Concierge, and Bvlgari, while remaining unique to Oriva Jewels. --- ## IMPORTANT VISUAL DIRECTION (BASED ON ACTUAL ORIVA INSTAGRAM PRODUCTS) Use the following as the primary visual inspiration: - Large marquise-cut diamond rings - Oval solitaire engagement rings - Pear-shaped diamond rings - Emerald-cut diamond studs - Tennis bracelets - Minimal white-gold and yellow-gold settings - Macro diamond photography - Soft nude/champagne backgrounds - Emerald velvet luxury backgrounds - Editorial lifestyle hand shots - Close-up ear stack styling The overall aesthetic should be: - Elegant - Minimal - Expensive - Editorial - Modern luxury - Soft cinematic lighting - High contrast diamond sparkle - Not flashy or overdesigned Avoid traditional jewellery-shop aesthetics such as heavy gold patterns, red backgrounds, crowded layouts, or discount-style banners. --- # DESIGN SYSTEM ## Color Palette - Pure Black #050505 - Deep Charcoal #111111 - Soft Ivory #F8F6F2 - Champagne Gold #D6B98C - Emerald Velvet Accent #0F3B2E - Diamond White #FFFFFF Use dark cinematic sections mixed with bright editorial sections. --- # TYPOGRAPHY Use luxury serif + modern sans-serif combination. Headings: elegant high-fashion serif. Body: clean modern sans-serif. Large typography with generous spacing. --- # WEBSITE EXPERIENCE The site must be: - Fully responsive - Mobile-first - Smooth scrolling - Premium animated - Interactive - Fast loading - SEO optimized Use subtle luxury animations only. No excessive motion. --- # MOBILE NAVIGATION (VERY IMPORTANT) Create a sticky bottom navigation bar exactly like the uploaded reference. Include 4 items: - Home - Collections - About - Contact Design: - Rounded top corners - Dark background - White icons - Active item highlighted with a soft glow - Always visible on mobile - Hide on desktop --- # HOMEPAGE STRUCTURE ## 1. CINEMATIC HERO SECTION Full-screen luxury hero. Background: - Slow-moving macro diamond reflections - Soft cinematic lighting - Floating sparkle particles - Subtle 3D depth - Dark luxury atmosphere Use one large marquise or oval diamond ring as the centerpiece. Headline: Timeless Brilliance, Crafted for Modern Elegance Subheading: Discover exceptional Natural and Lab Grown Diamond jewellery designed to celebrate life’s most meaningful moments. Buttons: - Explore Collections - WhatsApp Consultation On scroll: - Text fades elegantly - Background slightly zooms - Light reflections move subtly --- ## 2. FEATURED COLLECTIONS Create large editorial cards using the actual product types from Instagram. Collections: - Engagement Rings - Earrings - Bracelets - Pendants - Bridal Collection - Lab Grown Diamonds Use asymmetrical luxury layouts. Each card should have: - Full-width image - Minimal text - Soft hover zoom - “Explore Collection” link --- ## 3. BEST SELLERS Use a clean luxury product carousel. Show: - Marquise Solitaire Ring - Oval Hidden Halo Ring - Emerald Cut Stud Earrings - Tennis Bracelet - Pear Diamond Ring - Heart Drop Earrings Product cards should be large with generous whitespace. --- ## 4. EDITORIAL SHOWCASE Full-width section with emerald velvet background. Display a dramatic marquise-cut ring. Text: Designed to be remembered. This section should feel like a luxury magazine spread. --- ## 5. SHOP BY OCCASION Use circular image tiles. - Engagement - Wedding - Anniversary - Gift - Everyday Luxury --- ## 6. WHY ORIVA Four elegant icon cards: - Certified Diamonds - Natural & Lab Grown - Worldwide Shipping - Personalized Consultation Minimal glassmorphism cards. --- ## 7. INSTAGRAM GALLERY Use a masonry grid inspired by the uploaded Instagram feed. Mix: - Macro product shots - Hand shots - Ear stack shots - Velvet background shots - Lifestyle shots Hover effect: subtle zoom + “View on Instagram”. --- # COLLECTION PAGES Create dedicated pages for: - Engagement Rings - Earrings - Bracelets - Pendants - Bridal Collection - Lab Grown Diamond Jewellery - Natural Diamond Jewellery --- ## COLLECTION PAGE LAYOUT - Large cinematic banner - Editorial intro text - Filter sidebar - Luxury product grid - Full-width storytelling banner in the middle Filters: - Diamond Type - Shape - Metal - Price - Occasion - Style - Ring Size --- # PRODUCT CARD DESIGN Large image-first design. Features: - Soft shadow - Hover lift - Sparkle highlight - Quick view - Wishlist icon NO price emphasis. NO Add to Cart. Primary CTA: View Details --- # PRODUCT DETAIL PAGE (CRITICAL) This is the most important page. Layout: ## Left side - Large gallery - Fullscreen zoom - Alternate angles - Lifestyle images - Macro diamond close-ups ## Right side - Product name - Short luxury description - Customization options - WhatsApp CTA --- # CUSTOMIZATION OPTIONS Use elegant pill selectors. Depending on category: ## Rings - Ring Size - Metal Color - Diamond Type - Carat Range - Engraving ## Earrings - Metal Color - Diamond Type - Backing Type ## Bracelets - Length - Metal Color - Diamond Type Update a live “Selected Configuration” summary. --- # WHATSAPP INQUIRY SYSTEM Instead of Add to Cart, create a dynamic WhatsApp button. Button text: Enquire on WhatsApp Generate a custom message automatically. Example: Hello Oriva Jewels, I’m interested in: Product: Marquise Solitaire Ring Diamond Type: Lab Grown Metal: 18K Yellow Gold Ring Size: US 7 Carat: 2.5 ct Customization: Engraving requested Please share pricing and availability. The message must update based on customer selections. Use the official WhatsApp number placeholder. --- # ABOUT PAGE Luxury editorial layout. Headline: A Hong Kong-Based Fine Jewellery House Tell the story of: - Modern luxury - Certified diamonds - Thoughtful craftsmanship - Timeless design - Personalized service Use large photography and minimal text blocks. --- # CONTACT PAGE Include: - Hong Kong office mention - WhatsApp - Email - Consultation form - Appointment request - Worldwide shipping note - Embedded map section --- # FOOTER Elegant dark footer. Columns: - Collections - Customer Care - About - Contact Include: - WhatsApp - Instagram - Email - Shipping Policy - Return Policy - Privacy Policy - Diamond Guide - Jewellery Care Minimal luxury styling. --- # ANIMATIONS Use premium subtle animations: - Smooth fade-ins - Slow image zooms - Parallax on hero - Hover lift on cards - Text reveal on scroll - Soft sparkle effects Do NOT use: - Spinning objects - Fast transitions - Excessive parallax - Autoplay videos everywhere - Overly futuristic effects The motion should feel like a luxury fashion website. --- # PERFORMANCE Optimize for: - Mobile speed - WebP/AVIF images - Lazy loading - Minimal JavaScript - SEO - Core Web Vitals --- # CMS / ADMIN Create reusable product fields: - Name - Category - Collection - Description - Images - Diamond Type - Shape - Metal Options - Size Options - Carat Options - Customizable (yes/no) - WhatsApp SKU - SEO fields New products should be easy to add without editing code. --- # FINAL CREATIVE DIRECTION Imagine the website is being designed for a luxury diamond brand launching in Hong Kong, Dubai, Singapore, and the US. The customer should feel: - Exclusive - Confident - Inspired - Emotionally connected - Ready to inquire The experience should feel like browsing a luxury jewellery maison, not an online marketplace.
